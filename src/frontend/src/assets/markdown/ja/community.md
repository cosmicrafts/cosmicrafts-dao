# コミュニティ

![Community](communitybanner.webp)

## 概要

Cosmicrafts DAOは、単なるゲーム組織ではなく、共通のビジョンを持った活気あるコミュニティです。私たちのエコシステムは、プレイヤー、クリエイター、投資家、開発者を結集させ、Cosmicraftsの未来を共に形作ります。

::: info コミュニティ主導のアプローチ
この文書では、コミュニティ構造、参加メカニズム、コミュニティ主導のイニシアチブとプログラムについて概説しています。[ガバナンス](/governance)文書と組み合わせて読むことで、DAOがどのように機能するかの完全な理解が得られます。
:::

## コミュニティプログラム

### グラントプログラム

コミュニティグラントシステムは、Cosmicraftsエコシステムの拡張と改善に貢献するプロジェクトに資金を提供します：

<div class="table-scroll">

| グラントタイプ | 金額範囲 | 焦点領域 | 要件 |
|--------------|----------|----------|------|
| **マイクログラント** | $500～$5,000 | 小規模の改善、実験、コンセプト証明 | 簡略化された申請、急速な承認 |
| **プロジェクトグラント** | $5,000～$50,000 | 主要な機能、ツール、拡張機能 | 詳細な提案、マイルストーン、報告 |
| **エコシステムグラント** | $50,000～$250,000 | 変革的な統合、インフラストラクチャ | 包括的な計画、専門チーム、長期的なコミットメント |

</div>

グラント申請は透明なレビュープロセスを経て、コミュニティによって評価され、承認されます。

::: info グラント配布モデル
グラントの予算はDAOの財務から配分され、毎四半期にコミュニティ投票で承認されます。各グラントラウンドの優先事項は、エコシステムのニーズと戦略的方向性に基づいて設定されます。
:::

   - 長期的な価値創造の優先

## 長期的なビジョン

### コミュニティエボリューション

Cosmicrafts DAOの進化への道のり：

1. **フェーズ1: 形成**
   - コアコミュニティの構築
   - 初期プログラムの立ち上げ
   - 基本的な参加フレームワークの確立

2. **フェーズ2: 拡大**
   - グローバルなアウトリーチの拡大
   - プログラムの多様化と拡張
   - 自立したコミュニティリーダーの育成

3. **フェーズ3: 分散化**
   - 完全なコミュニティ自律性
   - ブランド開発のライセンス
   - 相互接続されたサブコミュニティのネットワーク

### コミュニティの成功指標

進捗を測定するためのキー指標：

<div class="table-scroll">

| 指標カテゴリ | 具体的な指標 | 測定頻度 |
|------------|------------|----------|
| **活動** | アクティブユーザー、メッセージ量、イベント参加 | 日次/週次 |
| **成長** | 新メンバー、保持率、紹介 | 週次/月次 |
| **健全性** | センチメント分析、コンフリクト解決率、モデレーションアクション | 週次 |
| **貢献** | 提出物数、貢献者数、貢献の多様性 | 月次 |
| **経済的** | 価値創造、コミュニティ財務健全性、持続可能性 | 四半期ごと |

</div>

::: info コミュニティデータダッシュボード
すべての主要コミュニティ指標は、透明性を確保し、データ駆動の意思決定を可能にするために、公開ダッシュボードで追跡されます。このアプローチは、DAOが継続的に進化し、コミュニティのニーズに適応することを可能にします。
:::

## 参加する方法

Cosmicraftsコミュニティに参加し、貢献するための実践的なステップ：

1. **参加**
   - Discordサーバーに参加
   - フォーラムアカウントを作成
   - コミュニティコールに参加

2. **学習**
   - ドキュメントを読む
   - FAQを探索
   - イントロダクションコースを受講

3. **貢献**
   - スキルに基づいたバウンティを見つける
   - コミュニティディスカッションに参加
   - ワーキンググループに参加する

4. **成長**
   - コミュニティレベルを上げる
   - メンターシップの機会を探す
   - 専門知識を共有し教える

::: info 今すぐ始める
今日から私たちのコミュニティに参加するには、公式Discordサーバーに参加し、#introductionチャンネルでこんにちはと言うことから始めてください。コミュニティマネージャーとオンボーディングチームが、あなたがすぐに貢献を開始するのを支援します。
:::
