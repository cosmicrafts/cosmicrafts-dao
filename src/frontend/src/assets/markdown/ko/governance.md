# 거버넌스

[[toc:2-2]]

## 소개

Cosmicrafts DAO는 투명하고 공정한 거버넌스 시스템을 통해 커뮤니티에 권한을 부여합니다. 모든 중요한 결정은 커뮤니티 투표를 통해 이루어져 각 이해관계자가 생태계의 미래에 대한 발언권을 가질 수 있도록 합니다.

::: info 읽기 가이드
이 문서는 Cosmicrafts DAO의 거버넌스 프레임워크를 설명하며, 의사결정 프로세스, 제안 시스템, 커뮤니티 참여에 중점을 둡니다. 이는 경제적 측면을 다루는 [토큰노믹스](/tokenomics) 문서를 보완합니다.

- **주요 초점**: 거버넌스 프로세스, 투표, 커뮤니티 의사결정
- **관련 문서**: 토큰 경제와 유틸리티를 다루는 [토큰노믹스](/tokenomics)
- **상호 참조**: 관련 토큰노믹스 섹션으로 연결되는 팁 박스 참조
:::

| 원칙 | 설명 | 구현 |

## SNS 통합

Cosmicrafts DAO는 Internet Computer의 [Service Nervous System (SNS)](https://internetcomputer.org/docs/building-apps/governing-apps/overview)를 거버넌스 인프라로 활용합니다. 이는 분산화된 의사결정을 위한 검증된 안전한 프레임워크를 제공합니다.

### 주요 매개변수

| 매개변수 | 값 | 설명 |
|-----------|---------|-------------|
| 최소 투표 | 100 SPIRAL | 최소 참여 |
| 투표 기간 | 7일 | 표준 투표 기간 |
| 최소 정족수 | 51% | 최소 참여 |
| 승인 임계값 | 66% | 필요 승인 비율 |

### 거버넌스 매개변수

| 매개변수 | 값 | 변경 가능 |
|-----------|---------|---------------|
| 지연 시간 | 24시간 | 예 |
| 제안 한도 | 1,000 SPIRAL | 예 |
| 실행 시간 | 48시간 | 예 |
| 거부 임계값 | 33% | 아니오 |

## 의사결정 프레임워크

### 제안 유형

| 유형 | 설명 | 승인 임계값 |
|--------|-------------|-----------------|
| 기술 | 프로토콜 업데이트 | 75% |
| 재무 | 자원 할당 | 66% |
| 커뮤니티 | 커뮤니티 이니셔티브 | 51% |
| 긴급 | 긴급 수정 | 90% |

### 제안 프로세스

1. **제출**
   - 제안 제출
   - 3일 토론
   - 피드백 기반 업데이트

2. **투표**
   - 7일 투표
   - 참여 추적
   - 결과 계산

3. **실행**
   - 실행 일정
   - 진행 상황 추적
   - 결과 보고

### 제안 요구사항

| 항목 | 설명 | 필수 여부 |
|---------|-------------|------------|
| 요약 | 간단한 개요 | 예 |
| 세부사항 | 전체 설명 | 예 |
| 예산 | 비용 추정 | 필요시 |
| 일정 | 실행 계획 | 예 |
| 위험 | 위험 분석 | 예 |

## 제안 시스템

### 제안 카테고리

| 카테고리 | 예시 | 처리 시간 |
|---------|-----------|---------------|
| 기술 | 프로토콜 업데이트 | 2-4주 |
| 재무 | 예산 할당 | 1-2주 |
| 커뮤니티 | 이벤트, 보상 | 1주 |
| 긴급 | 보안 수정 | 24-48시간 |

### 제안 수명 주기

1. **초안 단계**
   - 제안 준비
   - 커뮤니티 검토
   - 수정

2. **투표 단계**
   - 투표 개시
   - 일반 토론
   - 투표 기록

3. **실행 단계**
   - 실행 계획
   - 구현
   - 모니터링

4. **평가 단계**
   - 결과 측정
   - 피드백 수집
   - 개선 제안

## 거버넌스 로드맵

### 1단계: 설립 (1-6개월)
- 기본 투표 시스템 출시
- 초기 위원회 설립
- 제안 프레임워크 설정

### 2단계: 확장 (7-12개월)
- 고급 투표 메커니즘 추가
- 위원회 확장
- 제안 프로세스 개선

### 3단계: 성숙 (13개월+)
- 완전한 분산화 거버넌스 배포
- 고급 분석 도구 출시
- 중재 솔루션 통합
